### 课程模块说明 
 - **计算机网络** ：通过4个渐进式实验掌握网络协议栈原理，包含Socket编程、协议分析等实践。学生将从基础的Socket接口实验入手，逐步深入了解以太网协议、网络协议分析，最终掌握ICMP协议分析与FTP编程，为后续的网络开发和网络维护工作打下坚实基础。
 - **群智计算** ：理论实践结合，涵盖移动感知网络、群体智能算法等前沿领域。在理论学习部分，学生将系统学习群智计算的基本概念和算法原理；在实践环节，通过群智感知系统实践、移动计算实验以及任务协作系统开发等项目，培养学生运用群智计算解决实际问题的能力。
 - **Java高级编程** ：双轨教学（代码+UML），通过学生信息管理系统实战培养软件工程能力。学生不仅要掌握Java语言的高级特性，如类与对象、接口与继承等，还要学会使用UML进行系统设计，从而能够独立完成一个完整的软件项目开发。
 - **物联网综合实验** ：搭配虚拟仿真平台，熟悉物联网组网知识，提高对通信协议的理解。实验过程中，学生将接触到物联网的各个环节，包括实验资料中的程序源码学习，以及在实际项目中运用PyQT进行GUI开发、使用Node - RED进行流程编排、利用Python进行AI应用开发等，全面提升物联网开发能力。
 - **嵌入式系统原理与实验** ：该课程主要围绕嵌入式系统的原理展开教学，通过实验报告与代码的实践环节，让学生深入理解嵌入式系统的硬件架构和软件设计，掌握嵌入式系统的开发流程和调试技巧。
 - **管理运筹学（大作业）** ：以调度优化系统源码为基础，学生需要完成大作业项目。通过这个过程，学生将运用管理运筹学的理论知识，解决实际的调度优化问题，培养学生的系统分析和优化决策能力。
 - **模式识别与机器学习** ：通过实验项目，学生将学习模式识别和机器学习的基本算法和方法，掌握数据预处理、模型训练和评估等技能，能够运用这些技术解决实际的分类、聚类和预测问题。
