# 嵌入式系统原理与实验课程介绍 📚

本课程通过多个嵌入式系统实验，系统培养学生在嵌入式设备上进行深度学习任务的能力，理解如何利用嵌入式硬件加速深度学习计算，并掌握CUDA编程基础。

## 实验一：深度学习任务运行 🖥️

### 实验目的
- 掌握在嵌入式 GPU 设备上使用 Docker 容器运行深度学习任务的方法
- 理解如何利用嵌入式硬件加速深度学习计算

### 实验内容
- 启动 l4t-pytorch 容器并配置环境
- 运行图像分类任务，修改模型参数并观察性能变化

## 实验二：模型轻量化 🌐

### 实验目的
- 了解深度学习模型轻量化的基本原理
- 比较不同轻量化技术对模型性能和资源占用的影响

### 实验内容
- 量化、剪枝、知识蒸馏的实现方法
- 将轻量化模型部署到嵌入式设备上

## 实验三：CUDA编程基础 🔍

### 实验目的
- 了解 CUDA 编程的基础知识和并行计算原理
- 实现基本的并行计算任务，如矩阵加法和矩阵乘法

### 实验内容
- 理解 CUDA 内核的启动方式和线程块配置
- 使用共享内存优化矩阵乘法性能

## 实验四：GPU利用率监控与获取 ⚙️

### 实验目的
- 掌握在嵌入式 GPU 设备上监控和获取 GPU 利用率的方法
- 学习通过接口函数控制 GPU 的利用率

### 实验内容
- 安装并使用 jtop 工具查看 GPU 的利用率
- 使用脚本统计 GPU 的平均利用率

## 实验五：基于CUDA拦截的GPU虚拟化 💬

### 实验目的
- 掌握 CUDA 库拦截技术的实现方法
- 实践 GPU 资源限制和监控的方法

### 实验内容
- 通过修改环境变量实现 CUDA 库调用的拦截
- 编写和使用 CUDA 拦截库，限制 GPU 的利用率

## 实验六：GPU利用率动态调整

### 实验目的
- 实现 GPU 利用率的动态控制与调整

### 实验内容
- 使用 CUDA 拦截库，限制 GPU 的利用率
- 动态修改深度学习任务的运行状态

## 课程评价

这门课的难度适中，理论课考试容易，上课内容丰富，实验内容涉及深度学习任务的运行、模型轻量化、CUDA编程等多个方面，适合对嵌入式系统和深度学习有兴趣的学生。
